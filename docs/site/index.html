Real-Time PBR Rendering for Java

A modern 3D rendering engine with physically-based materials, glTF model loading, and a clean scene graph. Built on LWJGL 3 and Quarkus.

Built for Modern Rendering

Everything you need to render beautiful 3D scenes with physically accurate materials

🎨

PBR Materials

Cook-Torrance BRDF with metallic-roughness workflow. Albedo, normal, metallic, roughness, and AO texture maps for photorealistic surfaces.

📦

glTF 2.0 & OBJ Loading

Load industry-standard glTF binary (.glb) and Wavefront OBJ models with full PBR material extraction and texture support.

💡

Dynamic Lighting

Directional and point lights with shadow mapping. HDR rendering pipeline with configurable tone mapping and exposure control.

📐

Scene Graph

Hierarchical node system with entities, materials, and lights. Orbit and fly camera modes with smooth controls.

⚡

Built on Quarkus

Lightweight CDI container for dependency injection. Fast startup, low memory footprint, and clean lifecycle management.

🔧

Procedural Geometry

Generate spheres, boxes, cylinders, planes, and tori with configurable subdivisions. UV-mapped and ready for texturing.

Quick Start

1

Clone the repository

git clone https://github.com/rhajamor/fore.git
cd fore
2

Build the engine

./gradlew quarkusBuild
3

Run a demo scene

./gradlew runEngine

Switch scenes with keys 1-6. Orbit with left mouse, pan with middle mouse, zoom with scroll.
